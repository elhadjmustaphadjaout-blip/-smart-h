الفقرة الثانية: إنشاء المتغيرات والاتصال بقاعدة بيانات Firebase وقراءة البيانات
@Composable
fun SmartGreenHouseScreen(modifier: Modifier = Modifier) {

تعريف دالة واجهة المستخدم الرئيسية، وهي المسؤولة عن عرض جميع عناصر شاشة التطبيق.

var temperature by remember { mutableStateOf("0") }

إنشاء متغير لتخزين درجة الحرارة، وقيمته الابتدائية "0"، ويُحدّث الواجهة تلقائياً عند تغيره.

var humidity by remember { mutableStateOf("0") }

إنشاء متغير لتخزين قيمة الرطوبة.

var ph by remember { mutableStateOf("0") }

إنشاء متغير لتخزين قيمة الأس الهيدروجيني (pH).

var tds by remember { mutableStateOf("0") }

إنشاء متغير لتخزين قيمة المواد الصلبة الذائبة (TDS).

var fanState by remember { mutableStateOf(false) }

إنشاء متغير منطقي لحفظ حالة المروحة، وتكون في البداية متوقفة (false).

var pumpState by remember { mutableStateOf(false) }

إنشاء متغير منطقي لحفظ حالة المضخة.

var windowState by remember { mutableStateOf(false) }

إنشاء متغير منطقي لحفظ حالة النافذة.

LaunchedEffect(Unit) {

تشغيل مهمة تعمل مرة واحدة عند فتح الشاشة، وتستمر في الخلفية لقراءة البيانات من Firebase.

val database = FirebaseDatabase.getInstance()

الحصول على كائن يمثل قاعدة بيانات Firebase حتى يتمكن التطبيق من الوصول إليها.

while (true) {

بدء حلقة لا نهائية تجعل التطبيق يقرأ البيانات باستمرار.

database.getReference("Sensors/DHT22/Temperature")

الوصول إلى المسار الذي يحتوي على قيمة درجة الحرارة في Firebase.

.get()

إرسال طلب لقراءة البيانات الموجودة في هذا المسار.

.addOnSuccessListener {

تنفيذ الكود الموجود داخلها إذا نجحت عملية القراءة.

temperature = it.value.toString()

قراءة قيمة درجة الحرارة وتحويلها إلى نص ثم تخزينها في المتغير temperature ليتم تحديث الشاشة.

database.getReference("Sensors/DHT22/Humidity")

الوصول إلى مسار الرطوبة داخل قاعدة البيانات.

.get()
.addOnSuccessListener {
    humidity = it.value.toString()
}

قراءة قيمة الرطوبة وتحديث المتغير humidity.

database.getReference("Sensors/TDS")

الوصول إلى المسار المكتوب باسم Sensors/TDS.

.get()
.addOnSuccessListener {
    ph = it.value.toString()
}

قراءة القيمة الموجودة في هذا المسار وتخزينها في متغير ph.

ملاحظة: هنا يوجد خطأ برمجي، لأن المتغير ph يقرأ من مسار TDS وليس من مسار pH.

database.getReference("sensors/tds")

الوصول إلى مسار آخر باسم sensors/tds.

.get()
.addOnSuccessListener {
    tds = it.value.toString()
}

قراءة قيمة TDS وتخزينها في المتغير tds.

ملاحظة: هنا أيضاً يوجد اختلاف في كتابة المسار، حيث استُخدم sensors بحروف صغيرة بينما في الأسطر السابقة استُخدم Sensors بحرف S كبير. إذا كانت قاعدة البيانات تستخدم حرفاً كبيراً، فلن يتم العثور على البيانات لأن Firebase تفرق بين الأحرف الكبيرة والصغيرة.

database.getReference("Outputs/FanState")

الوصول إلى المسار الذي يحتوي على حالة المروحة.

.get()
.addOnSuccessListener {
    fanState = it.value.toString() == "true"
}

قراءة حالة المروحة، وإذا كانت القيمة "true" تصبح المروحة في التطبيق تعمل، وإلا تكون متوقفة.

database.getReference("Outputs/PumpState")

الوصول إلى مسار حالة المضخة.

.get()
.addOnSuccessListener {
    pumpState = it.value.toString() == "true"
}

قراءة حالة المضخة وتحديث المتغير الخاص بها.

database.getReference("Outputs/WindowState")

الوصول إلى مسار حالة النافذة.

.get()
.addOnSuccessListener {
    windowState = it.value.toString() == "true"
}

قراءة حالة النافذة وتحديث المتغير windowState.

delay(2000)

إيقاف الحلقة لمدة ثانيتين قبل إعادة قراءة جميع البيانات مرة أخرى، حتى لا يتم إرسال عدد كبير جداً من الطلبات إلى Firebase.

}
}

إغلاق الحلقة اللانهائية ثم إغلاق LaunchedEffect.

عرض قيمة درجة الحرارة الموجودة في المتغير temperature مع كتابة وحدة القياس (درجة مئوية).

Text("pH : $ph")

Text("TDS : $tds ppm")

Spacer(modifier = Modifier.height(30.dp))

Text(

Spacer(modifier = Modifier.height(10.dp))

Button(

onClick = {

fanState = !fanState

.getReference("Outputs/FanState")

.setValue(fanState)

modifier = Modifier.fillMaxWidth()

جعل الزر يمتد بعرض الشاشة بالكامل.

Text(
    if (fanState)
        "Fan ON"
    else
        "Fan OFF"
)

عرض عبارة Fan ON إذا كانت المروحة تعمل، أو Fan OFF إذا كانت متوقفة.

Spacer(modifier = Modifier.height(10.dp))

إضافة مسافة بين زر المروحة وزر المضخة.

Button(

pumpState = !pumpState

FirebaseDatabase.getInstance()

إرسال الحالة الجديدة للمضخة إلى Firebase.

Text(
    if (pumpState)

    else
        "Pump OFF"

إظهار حالة المضخة الحالية على الزر.

Spacer(modifier = Modifier.height(10.dp))

إضافة مسافة بين زر المضخة وزر النافذة.

Button(

إنشاء زر للتحكم في فتح وإغلاق نافذة البيت الزراعي.

windowState = !windowState

تغيير حالة النافذة من مفتوحة إلى مغلقة أو العكس.

FirebaseDatabase.getInstance()
    .getReference("Outputs/WindowState")
    .setValue(windowState)

إرسال الحالة الجديدة للنافذة إلى قاعدة بيانات Firebase.
